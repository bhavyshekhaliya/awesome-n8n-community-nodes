This directory currently lists the n8n community nodes published by [NativeShip](https://www.nativeship.io/nodes). Contributions from other publishers are welcome when they meet the [inclusion criteria](CONTRIBUTING.md).

Community nodes run third-party code in your n8n instance. This list is not a security audit or endorsement. Review a package's source, release history, permissions, dependencies, and license before installing it.
